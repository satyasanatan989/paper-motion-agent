# Contributing to PaperMotion AI 🎬

We welcome contributions from developers, animators, and AI researchers to make PaperMotion the world's finest code-to-video autonomous director!

## How to Contribute
1. **Fork the Repository** and clone your branch.
2. **Set up environment**:
   ```bash
   pip install -e ".[all]"
   pnpm install
   ```
3. **Run Tests**:
   ```bash
   python -m unittest discover tests
   ```
4. **Follow Conventional Commits**:
   - `feat: add 3D isometric cutout effect`
   - `fix: resolve voiceover sync drift on 60 FPS`
   - `docs: update Hugging Face token instructions`
5. **Submit a Pull Request** with before/after render snapshots.
